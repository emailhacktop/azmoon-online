## ✨ چه چیزی بهبود یافت؟

### ۱. امنیت
| مشکل قبلی | راه‌حل جدید |
|---|---|
| رمزها متن ساده در شیت | هش SHA-256 + Salt تصادفی |
| هر کسی می‌توانست نمره جعلی POST کند | تصحیح فقط در سرور، `c` هرگز به کلاینت نمی‌رود |
| پاسخ صحیح در `questions_*.js` قابل دیدن بود | حالت امن: سوالات بدون `c` ارسال می‌شود، نگاشت در Cache |
| Brute Force بی‌نهایت | Rate Limit + قفل ۱۵ دقیقه پس از ۵ تلاش |
| `innerHTML` و XSS | تمام خروجی با `textContent` و sanitize |
| تایمر قابل دستکاری با `time` در کنسول | تایمر بر اساس `Date.now()` و چک `elapsed` در سرور |
| `prompt()` رمز را متن ساده نشان می‌داد | فرم ورود استاندارد + HTTPS |

### ۲. معماری و قابلیت توسعه
- **بانک یکپارچه:** به جای ۴ فایل جدا (`questions_*.js`) یک فایل `questions_db.json` با ساختار:
  ```json
  {
    "categories": [{ "id":"history_geo", "label":"تاریخ و جغرافیا", "groups":["تاریخ","جغرافیا","ترکیبی"] }],
    "questions": [{ "uid":"...", "category":"history_geo", "group":"تاریخ", "q":"...", "a":[...], "c":"..." }]
  }
  ```
- **دسته جدید در ۳۰ ثانیه:** در پنل مدیریت → تب دسته‌ها → «افزودن دسته» (مثلاً `science` با گروه‌های `فیزیک,شیمی,زیست,ترکیبی`) → افزودن سوالات → ذخیره در سرور. بدون تغییر حتی یک خط کد!
- **گروه‌های پویا:** منطق انتخاب سوال دیگر `4+4+2` هاردکد نیست؛ بر اساس گروه‌های موجود هر دسته به‌صورت متوازن توزیع می‌کند.
- **پنل مدیریت:** بدون نیاز به ویرایش فایل، از مرورگر سوال اضافه/ویرایش/حذف، دسته بساز، کاربر بساز، رمز عوض کن، لاگ ببین، خروجی CSV/JSON بگیر.

### ۳. کیفیت کد
- شافل Fisher-Yates به جای `sort(()=>Math.random()-.5)` بایاس‌دار
- اعتبارسنجی ورودی (طول، نوع، فرمول injection `=+-@`)
- قفل همزمانی `LockService` برای `appendRow`
- توکن با انقضا ۲ ساعته در `CacheService`
- `doGet` برای health-check و `doOptions` برای CORS

## 🚀 شروع سریع (حالت آفلاین بدون سرور)

فقط `index.html` و `assets/questions_db.json` را روی هر هاست استاتیک (حتی GitHub Pages) آپلود کن. بدون نیاز به Google Sheets، آزمون کار می‌کند (تصحیح در مرورگر).

## 🔐 حالت امن کامل (پیشنهادی)

1. به [script.google.com] برو → پروژه جدید → فایل‌های `gas/Code.gs` و `gas/appsscript.json` را جایگزین کن.
2. `setup()` را یک‌بار Run کن (شیت‌های `Users`, `StudyLog`, `ExamLog`, `QuestionsDB` ساخته می‌شود + کاربر `admin/Admin123!`).
3. Deploy → Web App → Execute as **Me**, Access **Anyone**.
4. URL را در `index.html` و `admin.html` در متغیر `WEB_APP_URL` بگذار.
5. وارد `admin.html` شو → لاگین → «بارگیری از سرور» → اگر خالی بود «ذخیره در سرور» بزن تا ۴۰۰ سوال آپلود شود.

از این به بعد:
- آزمون: `getExam` → سوالات بدون پاسخ → `submitExam` → نمره از سرور
- مطالعه: نیاز به لاگین معتبر
- مدیریت: همه چیز با توکن

## 🔑 مدیریت رمز

- پنل → تب تنظیمات → «تغییر رمز مدیر» (نیاز به رمز فعلی)
- یا در شیت `Users` ردیف admin را حذف و دوباره `setup()` اجرا کن.
- تمام رمزها هش می‌شوند؛ حتی ادمین هم متن ساده را نمی‌بیند.

## ➕ افزودن دسته جدید - مثال

پنل → دسته‌ها → 
- شناسه: `science`
- عنوان: `علوم تجربی`
- آیکون: `🔬`
- رنگ: `#0ea5e9`
- گروه‌ها: `فیزیک,شیمی,زیست,ترکیبی`

سپس تب سوالات → فیلتر دسته `علوم تجربی` → افزودن سوال → ذخیره در سرور → تمام! در صفحه اصلی دسته جدید ظاهر می‌شود.
